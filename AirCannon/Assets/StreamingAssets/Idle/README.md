# Idle — 대기 화면 영상

- 이 폴더에 넣은 영상 하나를 대기 화면에서 무한 반복 재생합니다 (AVPro Video, 소리 끔).
  - **파일 이름은 상관없습니다.** 확장자(mp4, mov, webm, avi, mkv, m4v, wmv)로 찾습니다.
  - 영상이 여러 개면 이름순 첫 번째 파일을 쓰고 경고 로그를 남깁니다. 한 개만 넣어 두세요.
  - 폴더 이름은 `aircannon.json`의 `idleVideoFolder` (StreamingAssets 기준, 기본 `Idle`)로 바꿀 수 있습니다.
  - 빌드 후에는 `<앱>_Data/StreamingAssets/Idle/`의 파일만 바꾸면 다시 빌드하지 않고 반영됩니다(앱 재시작 필요).
- 권장: H.264 MP4, 세로 1080x1920 (또는 2160x3840). 처음과 끝 장면이 이어지게 만들면 반복 이음매가 보이지 않습니다.
- 영상이 없거나 열 수 없으면 대기 화면은 검은 화면으로 두고 로그만 남깁니다(AVPro 로고는 표시하지 않음).
- `idle_temp.mp4`는 임시 영상입니다. 실제 영상을 넣을 때 지우세요.
